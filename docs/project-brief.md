# Project Brief

## Project Title

AutoParts B2B Sales Intelligence and Customer Retention Agent

## Business Scenario

A fictional company distributes automotive parts to retailers,
repair shops, and regional wholesalers.

The company currently receives sales, customer, product, campaign,
inventory, and payment data from multiple operational files.

Management needs a unified analytical system to understand business
performance and determine which actions should be taken.

## Main Stakeholders

- General Manager
- Sales Manager
- Finance Manager
- Marketing Manager
- Inventory Manager
- Sales Representatives

## Main Business Questions

1. How are revenue and gross profit changing over time?
2. Which customers generate the most revenue and profit?
3. Which customers are reducing their purchases?
4. Which customers are at risk of becoming inactive?
5. Which products have high sales but low profit margins?
6. Which campaigns generate profitable customer behavior?
7. Which products may require inventory replenishment?
8. Which customers should the sales team contact today?

## Initial Project Scope

The first version will include:

- Synthetic B2B sales data
- Data validation and cleaning
- PostgreSQL analytical database
- SQL business analysis
- Customer RFM segmentation
- Campaign performance analysis
- Power BI management dashboard
- Automated n8n workflow
- Read-only AI analytics agent

## Out of Scope for the First Version

- Real ERP integration
- Real-time streaming
- Mobile application
- Complex demand forecasting
- Autonomous data modification
- Multiple cooperating AI agents
