# AutoParts B2B Sales Intelligence

An end-to-end data analytics and AI project for a fictional wholesale
automotive parts distributor.

## Business Problem

The company needs a reliable system to monitor sales performance,
analyze customer behavior, evaluate marketing campaigns, identify
at-risk customers, and generate actionable recommendations for sales
managers.

## Project Goals

- Clean and validate raw sales data
- Store analytical data in PostgreSQL
- Define business KPIs
- Analyze customer purchasing behavior
- Segment customers using RFM analysis
- Evaluate campaign performance and ROI
- Build an interactive Power BI dashboard
- Automate daily reporting with n8n
- Build an AI agent for business questions and recommendations

## Planned Technology Stack

- Python
- Pandas
- PostgreSQL
- SQL
- Power BI
- n8n
- Streamlit
- OpenAI API
- Docker
- Git and GitHub

## Project Status

Project setup and business requirements definition.

## Data Disclaimer

The dataset used in this project is synthetic and is designed to
simulate realistic B2B automotive parts distribution operations.
